# 妆译 Agent 工作流与实现

妆译将参考妆容图转成可执行的分步教程。LangGraph 编排妆面分析、技法检索、个性化步骤生成和审核。Qwen-Agent 负责调度产品资料补全工具。视觉与文本推理通过配置的 OpenAI 兼容服务调用。

## 教程生成

1. **参考图分析**：识别可见的妆效，记录部位、妆效、颜色、质地、强度及图片依据。
2. **技法检索**：按妆效目标从本地 JSON 技法库筛选卡片，结合部位和用途规则、关键词匹配排序，每个目标最多保留三张候选卡。[技法卡来源与重建](technique-library.md)
3. **个性化编排**：结合用户确认的面部特征、熟练度和可用工具，为每个目标生成操作步骤。步骤包含技法来源、动作、完成标准、产品要求和与面部锚点关联的绘图参数。
4. **审核与展示**：程序校验步骤与妆效目标、技法卡和产品要求的对应关系，再进行模型审核。步骤图用 SVG 标出落点和方向，关键步骤可基于标准底图与局部蒙版合成妆效。

完成共享分析后，步骤生成与产品匹配分别作为后台任务运行，各自保存进度和结果。产品结果按目标、技法和类别关联已有步骤。教程保存生成时的用户资料、产品与技法快照，方便回看。

## 产品核验与匹配

- **目录优先**：按品牌别名、品名和色号查询 [商品目录](../data/product_catalog.json)，从候选记录中读取来源和已核对的字段。
- **联网补充**：Qwen-Agent 调用搜索与页面读取工具发现来源。独立搜索适配器支持 AIHubMix 搜索和百炼原生搜索。官方字段由页面正文中的具体摘录支持，社媒搜索摘要单独展示。
- **澄清与确认**：产品身份存在歧义时，任务保存已收集的来源并等待用户补充系列或色号。核验结果由用户确认后进入化妆包。
- **教程匹配**：优先使用符合类别和用途的已有产品，再参考图片取色、色彩家族和妆效对候选排序。目录商品作为供用户查找的参考。

## 状态与配置

SQLite 保存个人资料、产品、任务状态和教程快照。LangGraph 使用 SQLite 检查点记录图状态。搜索次数、页面读取数量和后台任务时长由 [搜索预算](../data/search_budget.json) 与 [任务预算](../data/task_budget.json) 配置。

`QWEN_BASE_URL` 配置模型服务地址，`QWEN_VISION_MODEL` 配置视觉模型，`QWEN_AGENT_MODEL` 配置产品核验模型，`TUTORIAL_TEXT_MODEL` 可单独配置教程生成和审核使用的文本模型。启动方式和配置步骤见 [README](../README.md)。
