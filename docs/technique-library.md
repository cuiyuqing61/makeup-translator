# 技法卡来源与重建

2026-10-08 将原有 10 张基础卡与 18 张团队草稿卡全部撤出运行时，改用从官方公开教程重新整理的卡片。当前共 29 张，覆盖底妆与鼻部修容 6、眉妆 3、眼妆 9、面颊（腮红、修容、高光）6、唇妆 5。鼻部修容卡对应[欧莱雅巴黎鼻部修容教程的第 2 步](https://www.lorealparisusa.com/beauty-magazine/makeup/face-makeup/nose-contour)。每张卡都记录来源机构、文章标题、原文 URL、对应章节和查阅日期，包含具体动作、完成信号、简化做法、适用调整、工具与产品类别。卡片是对公开教程的重新编写，不是原文或配图的复制。

主来源是[欧莱雅巴黎官网 Beauty Magazine](https://www.lorealparisusa.com/beauty-magazine/makeup)，用于底妆、眉眼、腮红、修容、高光及唇妆的通用操作。中文补充来源是毛戈平形象设计艺术学校的[眉妆](https://www.maogp.com/news_nr/index/730/39300.html)、[眼妆](https://www.maogp.com/news_nr/index/547/41283.html)和[腮红与渐变唇](https://www.maogp.com/news_nr/index/730/41888.html)公开文章。后者是学校编辑发布的彩妆资讯，不能表述为毛戈平本人对本项目授课、审阅或背书。品牌和学校文章均不是经过独立同行评审的技术标准；部分内容含商品推广或特定审美偏好，因此卡片只保留可操作的上妆动作，并允许用户根据参考图和自身偏好调整。

眉头梳柔卡允许“只用干净眉刷整理毛流”的无需产品类别；若教程选择眉妆产品类别，仍需明确实际补色或定型操作。卡库由 `scripts/build_sourced_techniques.py` 生成，类别变更必须同步写回生成脚本。

数据源在 `scripts/build_sourced_techniques.py`，运行 `python scripts/build_sourced_techniques.py` 会重建 `data/knowledge_cards.json`。运行时只加载这一个 JSON；旧草稿文件和追加逻辑已删除。新 ID 与历史记录中的旧 ID 不重用，已保存教程的步骤与示意图快照不会被新库悄悄改写。

每一步生成结果会保存所用卡片的原文链接和章节，网页可直接打开原文。当前所有卡片维持 `review_status=draft`：出处已标注，但尚未请专业化妆师逐张复核，也未完成用户跟练验证。官网可用性可能变化，失效链接应重新核实并替换来源，不能自动改成无来源卡。

粉底、遮瑕、定妆粉、眉胶、眼部打底、润唇膏和唇线笔等卡片另有具体产品用途约束。项目现有商品目录的 `base`、`brow`、`lip` 类别偏宽；只有产品名称明确显示用途时才会自动匹配，否则提示用户核实或补录，避免把同一大类里的不同产品互相替代。
